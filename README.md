# 킥오프코믹스 인스타 자동 업로드

- `posts/<폴더>/` 에 `1.jpg, 2.jpg …` + `caption.txt` (+ 예약하려면 `post_at.txt` = `2026-10-22 19:00`, 한국시간)
- 매시 7분에 시간이 된 게시물을 올리고 `posted.txt` 에 링크를 남깁니다.
- 바로 올리기: Actions → 인스타 업로드 → Run workflow → 폴더 이름 입력
- 필요한 비밀값: `IG_TOKEN` (Settings → Secrets and variables → Actions)
- 토큰은 매월 1일·15일 자동 연장됩니다.

## 매 게시마다 자동으로 하는 것 (2026-10-20 추가)
- 캡션 규칙: 해시태그 5개까지만 (넘으면 앞에서 5개만 남김), 면책 문구 없으면 추가
- 이미지 대체 텍스트: `alt.txt` 가 없으면 캡션 첫 줄로 자동 생성
- 첫 댓글: 지난 편 MVP 투표를 집계해서 결과 + 이번 편 투표 안내 (투표 3표 미만이면 안내만)
- 스토리: `story_1.jpg`~`story_4.jpg`(장면별 9:16)를 순서대로 4장 올림. 없으면 4컷 첫 장 1장 (안 되면 건너뜀)
- 공동 게시: `collab.txt` 에 아이디를 적으면 초대 (최대 3개)
- 결과는 `posted.txt` 둘째 줄에 기록
- 음악·댓글 고정은 인스타 API로 안 됨 → 앱에서 직접
